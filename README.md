# 粉笔公考 · 静态资源导航站

> 域名：**fbgk.net** —— 聚合考公 / 考研课程目录、免费笔记网盘群与课程更新日志的一站式导航站。

一个**单文件纯静态网站**：整站只有 `index.html`，零外部依赖（CSS、JavaScript、图标全部内联），可直接部署到 **Cloudflare Pages**。

---

## 一、功能特性

| 功能 | 说明 |
| --- | --- |
| 顶部导航栏 | 左侧 Logo + 站名；中部 4 个文字导航；右侧自动显示**当天日期**（年/月/日 + 星期） |
| 主视觉 | 大标题「粉笔公考」渐变字 + 醒目展示域名 `fbgk.net`（仅展示，非链接） |
| 内容卡片 | 4 张资料入口卡片，含全部分类标签，点击**新窗口**打开对应腾讯文档 |
| 响应式 | `clamp()` 流式字号 + 自适应网格，手机 / 平板 / PC 自动缩放；窄屏导航自动换行 |
| 悬浮按钮 | 滚动超过 320px 出现，点击平滑返回顶部 |
| QQ 一键复制 | 页尾两个 QQ，点击即复制并弹出「QQ已复制」提示（含无 Clipboard API 时的兼容降级） |
| 视觉风格 | 浅色明亮渐变主题、玻璃拟态导航、漂浮光斑、卡片悬浮微动效 |

---

## 二、目录结构


## 四、浏览器兼容

支持所有现代浏览器（Chrome / Edge / Firefox / Safari）。使用了 `backdrop-filter`、`background-clip: text`、`clamp()` 等特性；在不支持 `backdrop-filter` 的旧浏览器中，导航栏会退化为半透明白底，其余功能不受影响。
